## Calm alternative

[Review the calmer homepage](https://www.figma.com/design/L2rtizEUpABtAXHgCjgUdd/Cloud-Lens?node-id=16-3858). Separate section beside review 01, which is preserved. The screen is 1440 × 1080 with 48 px content gutters and 32 px section gaps. Four measures share one summary band; one chart includes two compact AWS-icon cost contributors; two ready recommendations form a short review list. Service inventory, the full technical explanation and detailed measurement ledger move into intended drill-downs. Values retain the same scenario contract. This is a Figma design proposal, not an implemented interactive route or application change.

Header refinement: client identity appears only in the sidebar, labelled Demo client. The header has one provenance/completeness line, a month selector, account scope, cost basis and currency/tax context. Removed the repeated client/account metadata, separate simulation chip, separate completeness indicator and generic Client workspace top-bar text. The header is 10 px shorter.

Decisions: comparable periods for change; cumulative actual, forecast and budget on the same USD scale; service mix plus dollar change; observed usage separated from unconfirmed causes; evidence before approval; defined measurement window for verified run rate. A network Sankey belongs in the investigation view when backed by modeled flow records, rather than added decoratively to the homepage.
